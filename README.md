# Smart College Event Planner

Smart College Event Planner is a campus event management web application designed to help students and organizers discover, schedule, and keep track of college events in one place.

## Overview
Planning workshops, technical talks, cultural meetups, and club sessions on campus often leads to scattered announcements, missed schedules, and unclear event details. This project brings event discovery and event creation into a single, easy-to-use platform so organizers can publish structured event information and attendees can browse upcoming activities effortlessly.

## Live Demo
- **Web Application:** https://smart-college-event-planner-v7z9.vercel.app

## What It Offers
- **Centralized Event Hub:** A single place to view upcoming campus events along with their descriptions, categories, dates, timings, and capacities.
- **Streamlined Event Creation:** Allows organizers to publish new events with clear schedule and capacity details instead of sharing unformatted messages across groups.
- **Category-Driven Organization:** Helps students quickly spot events that match their interests, such as workshops or campus activities.
- **Cloud-Backed Persistence:** Stores event data reliably in the cloud so updates stay in sync across sessions and devices.

## Tech Stack & Architecture
- **Frontend:** TypeScript-based web interface deployed on Vercel, built for a clean and accessible user experience.
- **Backend:** Python with FastAPI, handling request validation and connecting the application cleanly to cloud storage.
- **Database:** Supabase, providing persistent storage for all campus events.
